## 📝 Como executar o projeto

1. **Baixe e extraia** o arquivo `.zip` disponível no link acima.

   * Alternativamente, é possível instalar o arquivo ZIP diretamente via Git. O clone também é possível, mas **não recomendamos**.
2. **Inicie o site** a partir da pasta `HOME`.
3. **Abra** o arquivo `início.html`.

⚠️ **Importante:**
Por algum motivo, o CSS do site só é carregado corretamente quando executado com a extensão **Live Server** no **Visual Studio Code**.
Pedimos desculpas pelo transtorno e recomendamos rodar dessa forma para uma melhor experiência.

---

## 💡 Funcionalidades do site

* **Busca por CEP:** Digite um CEP e selecione uma especialidade médica para encontrar clínicas ou médicos disponíveis.
* **Perfis de médicos e clínicas:** Visualize perfis completos e agende consultas diretamente.
* **Design responsivo:** O site se adapta automaticamente a diferentes tamanhos de tela.

---

## 🔗 Navegação (Navbar e Rodapé)

* **Home:** Página inicial com busca e destaques.
* **Sobre:** Apresenta a equipe do projeto e a missão da empresa Clinic+.
* **Serviços:** Explica como funcionam a busca, o filtro de clínicas e o agendamento de consultas.
* **Contato:** Informações de contato da empresa.
* **Login/Cadastro:** Acesso para médicos e pacientes.

  > *Observação:* As informações podem ser fictícias; é necessário preencher o formulário corretamente para ser redirecionado ao perfil.
* **Perfil:**

  * **Paciente:** Visualiza dados pessoais, consultas e exames pendentes.
  * **Médico:** Acesso às informações profissionais e consultas agendadas.
  * Ambos os perfis possuem a opção de **logout**.

## 💡 Website Features

* **ZIP Code Search:** Enter a ZIP code and select a medical specialty to find available clinics or doctors.
* **Doctor and Clinic Profiles:** View detailed profiles and schedule appointments directly.
* **Responsive Design:** The site adjusts seamlessly to different screen sizes.

---

## 🔗 Navigation Overview (Navbar & Footer)

* **Home:** Homepage with search tools and highlights.
* **About:** Introduction to the project team and the Clinic+ mission.
* **Services:** Overview of search functionality, clinic filters, and appointment scheduling.
* **Contact:** Company contact information.
* **Login/Register:** Access for doctors and patients.

  > *Note:* Information provided in the form may be fictional; correct completion is required to access the profile page.
* **Profile:**

  * **Patient:** View personal data, consultations, and pending exams.
  * **Doctor:** Access professional details and appointment management.
  * Both profiles include a **logout** option.
